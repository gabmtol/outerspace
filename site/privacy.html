Privacy

Last updated: October 24, 2026

OuterSpace collects no data. It has no accounts, no analytics, no telemetry and no crash reporting. It does not send anything about you or your PC to its authors or to anyone else.

What stays on your PC

  • Settings and the access token are stored in %LOCALAPPDATA%\com.gabmtol.outerspace\config.json. The token protects the local MCP server; it never leaves your PC.
  • Logs are stored in the logs folder next to it: an app log (kept for 7 days) and an action log listing what agents did — which tool, which program was launched, where they clicked. The text agents type is not logged, only its length. Screenshots are never saved to disk.
  • Uninstalling and choosing to delete app data removes all of it.

Network connections

  • The MCP server listens on 127.0.0.1 only, so it can't be reached from other computers, and it refuses requests from web pages.
  • OuterSpace connects to the internet in exactly one case: when you click Install driver, it downloads Parsec's official virtual display driver installer from builds.parsec.app and checks its SHA-256 before running it. That request goes to Parsec, under Parsec's privacy policy.

Your AI agent

OuterSpace gives the AI agent you connect (Claude Code, Codex CLI, OpenCode, or another MCP client) screenshots of the virtual display, the titles of windows on it, and the results of the actions it takes. What that agent does with them — including sending them to its provider's servers — is governed by that agent's and provider's own privacy policies, not by OuterSpace. Don't put anything on the virtual display that you wouldn't show your agent.

This website

This site is hosted on GitHub Pages and uses no cookies, analytics or third-party scripts. GitHub may log visitors' IP addresses for security, as described in the GitHub Privacy Statement. Downloads are served by GitHub Releases.
